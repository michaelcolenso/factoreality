**Problem types to look for:**

- [ ] **Duplicate** — same service/code billed twice on the same date
- [ ] **Quantity error** — billed more units/hours/days than received
- [ ] **Phantom charge** — service not in my medical record
- [ ] **Canceled item** — billed for something scheduled then canceled
- [ ] **Unbundling** — separate charges for steps that belong in one code
- [ ] **Upcoding** — billed a more complex/expensive code than the care given
- [ ] **Room/board/time mismatch** — extra days, private room not received, OR time off
- [ ] **Wrong patient info** — name / DOB / member ID incorrect
- [ ] **Wrong/no insurance** — processed as self-pay when insured, or wrong plan
- [ ] **Secondary insurance not billed**
- [ ] **EOB mismatch** — bill exceeds the "patient responsibility" on the EOB
- [ ] **Billed above allowed rate** — in-network provider billing above contracted amount
- [ ] **Surprise / balance bill** — out-of-network ER, or OON clinician at in-network facility

## Decision

- [ ] **Errors found** → go to Module 2 (Dispute) with this checklist as evidence
- [ ] **No errors, balance unaffordable** → Module 3 (Negotiate) and/or Module 4 (Aid)
- [ ] **Claim denied** → Module 5 (Appeal)
- [ ] **Already in collections** → Module 7 (Validate & defend) — but still apply for aid
